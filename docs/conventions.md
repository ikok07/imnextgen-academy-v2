### Project conventions

---
In order for the [auto modules installer](https://github.com/I-M-NextGen/imnextgen-academy-updater.git) to work there need to be certain conventions used

---

`@/di/container.ts` - `loadExternalModules(container: Container)`

`@/di/types/types.ts` - `const MODULE_DI_SYMBOLS` and `interface MODULE_RETURN_TYPES`

`@/i18n/request.ts` - `async function loadExternalModuleMessages()`
