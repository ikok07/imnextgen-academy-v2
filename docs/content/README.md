# Уроци-статии

Тук живее съдържанието на уроците, които не са видео. Един файл = един урок.
Базата се пълни от тези файлове, а не обратното — ако смениш текст през админ
панела, следващото качване ще го презапише.

## Структура

```
docs/content/
├── module-2-bridge/          Модул 2, секция „Модерен JavaScript: мостът към React“
└── module-3/
    ├── s1-zashto-react/
    ├── s2-jsx-props/
    └── ...
```

Името на файла започва с номер — той определя реда в секцията.

## Frontmatter

```
---
module: "Модул 3: React & NextJS"      заглавието на модула в базата (трябва да съществува)
section: "Компоненти, JSX и props"      секцията; създава се, ако я няма
sectionId: "uuid"                       по избор - за да се ползва съществуваща секция
sectionOrder: 1                          подредба на секцията в модула
title: "props: данните идват отгоре"
label: "react-2-02-props"               уникален; по него се разпознава урокът в базата
---
```

Съответствието с базата е по `label`, не по заглавие — преименуването на урок не
създава дубликат.

## Команди

```bash
node docs/scripts/check-content.mjs                     # проверява всичко, изпълнява решенията на задачите
npx tsx docs/scripts/sync-content.ts                    # проба: показва какво би направил
npx tsx docs/scripts/sync-content.ts --apply            # качва в базата
npx tsx docs/scripts/sync-content.ts --apply --only=module-3
npx tsx docs/scripts/sync-content.ts --apply --remove   # маха уроците от базата (файловете остават)
```

`check-content.mjs` не просто чете файловете: изпълнява решението на всяка задача
срещу собствените ѝ тестове. Ако някое решение не минава, проверката пада.

## Интерактивни блокове

Пишат се като ограден код блок, чийто „език“ е името на блока. Частите се делят
с ред само от `---`. Ако първата част започва с `{`, тя е JSON конфигурация.

| Блок | За какво |
| --- | --- |
| `quiz` | въпрос с отговори, обяснение и отчитане на прогрес |
| `run` | код, който курсистът може да промени и изпълни в страницата |
| `task` | задача с автоматична проверка: конфигурация, стартов код, решение |
| `sandbox` | React или vanilla песъчник (Sandpack), няколко файла |
| `submit` | задача за преглед от ментор — предава се в академията |
| `callout` | каре: `info`, `tip`, `warn`, `danger` |
| `reveal` | скрито съдържание зад бутон |
| `steps` | номерирани стъпки (всяка част е стъпка) |
| `takeaways` | обобщение в края на урока |

Примери за всеки блок има във всеки от съществуващите уроци.

**Важно:** вътре в `callout`, `reveal`, `steps` и `takeaways` НЕ може да има
ограден код блок — той прекъсва външния блок. Проверката го хваща.

## Преглед преди качване

При пуснат `npm run dev`: `http://localhost:3000/dev/lesson-preview` показва всеки
файл от `docs/content` през истинския рендерер на уроците. Страницата не съществува
извън режим на разработка.
