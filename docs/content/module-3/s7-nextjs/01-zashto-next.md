Досега приложението ти беше едностранично: браузърът сваля празен HTML и празен `div`, после JavaScript-ът построява всичко.

```steps
{"title":"Какво не е наред с това"}
---
**Празен екран в началото.** Докато JavaScript-ът се свали и изпълни, потребителят гледа нищо.
---
**Google вижда празна страница** в най-лошия случай, а в най-добрия — изчаква и вижда нещо по-късно.
---
**Данните тръгват късно.** Заявката към API-то започва чак след като компонентът се появи.
---
**Няма сървър.** Тайните ключове нямат къде да живеят, а всяка операция изисква отделен бекенд проект.
```

Next.js е React с добавен сървър.

## Трите неща, които решава

```steps
---
**Рисуване на сървъра.** HTML-ът пристига готов: потребителят вижда съдържание веднага, търсачките — също.
---
**Данните се вземат на сървъра**, до базата, без обиколка през браузъра. Ключовете остават на сървъра.
---
**Пълноценен бекенд** в същия проект: адреси за API, обработка на форми, автентикация.
```

## Как изглежда разликата

**Едностранично приложение (Vite):**

```
Браузър → празен HTML → сваля JS → изпълнява React → заявка към API → показва данни
```

**Next.js:**

```
Браузър → сървърът взима данните и рисува HTML → готова страница → JS оживява интерактивните части
```

Второто е по-бързо за гледане и по-бавно за първи клик. За повечето сайтове размяната е изгодна.

## Кога Next и кога не

| Ползвай Next.js | Остани на Vite |
| --- | --- |
| Сайт, който трябва да излиза в Google | Вътрешен инструмент зад вход |
| Магазин, блог, каталог | Табло за администратор |
| Съдържанието трябва да е видимо веднага | Приложение, което прилича повече на програма |
| Нужен е и бекенд | Вече имаш отделен бекенд |

```callout
{"type":"info","title":"App Router срещу Pages Router"}
---
Next има две системи за маршрути. Старата (`pages/`) още се поддържа и ще я срещнеш в съществуващи проекти. Новата (`app/`) е стандартът за нови проекти от 2023 г. насам и е това, което учим тук. Внимавай, когато търсиш в интернет — много статии още описват старата.
```

## Нов проект

```
npx create-next-app@latest my-app
```

Въпросите, които ще ти зададе, и разумните отговори:

```steps
---
**TypeScript?** За този модул — не. В работата — да.
---
**ESLint?** Да.
---
**Tailwind CSS?** Да.
---
**`src/` директория?** Въпрос на вкус; да, ако обичаш кодът да е отделен от конфигурацията.
---
**App Router?** Да, задължително.
---
**Turbopack?** Да — по-бърз е при разработка.
```

После `npm run dev` и проектът е на `http://localhost:3000`.

```takeaways
- Next.js е React плюс сървър: рисуване на сървъра, данни на сървъра и бекенд в същия проект.
- Готовият HTML решава празния екран и видимостта в търсачките.
- App Router (`app/`) е новата система; `pages/` е старата.
- Не всеки проект има нужда от Next — таблата зад вход спокойно остават на Vite.
