В Next.js няма `Routes` и `Route`. Маршрутът е папка, а страницата — файл в нея.

```
app/
├── layout.jsx          общ изглед за целия сайт
├── page.jsx            /
├── about/
│   └── page.jsx        /about
├── courses/
│   ├── page.jsx        /courses
│   ├── layout.jsx      общ изглед за раздела
│   └── [slug]/
│       └── page.jsx    /courses/react
└── (marketing)/        група - НЕ влиза в адреса
    ├── pricing/
    │   └── page.jsx    /pricing
    └── contact/
        └── page.jsx    /contact
```

```steps
{"title":"Правилата"}
---
**Само `page.jsx` прави адрес достъпен.** Папка без такъв файл не е страница — просто подредба.
---
**`layout.jsx`** обвива себе си и всичко под себе си. Вложените изгледи се наслагват.
---
**`[скоби]`** правят частта от адреса динамична.
---
**`(скоби)`** групират папки, без да променят адреса — за подредба и за различни изгледи.
```

## Основният изглед

```javascript
// app/layout.jsx
import "./globals.css";

export const metadata = {
  title: "Академия",
  description: "Научи уеб разработка от нулата"
};

export default function RootLayout({children}) {
  return (
    <html lang="bg">
      <body>
        <header>
          <nav>меню</nav>
        </header>
        <main>{children}</main>
        <footer>подвал</footer>
      </body>
    </html>
  );
}
```

Основният изглед е задължителен и е единственото място, където пишеш `<html>` и `<body>`. `children` е текущата страница — това е `Outlet` от React Router, само че по подразбиране.

```callout
{"type":"tip","title":"Изгледите не се пречертават"}
---
При навигация между страници под един изглед, самият изглед остава жив. Менюто не мига, превъртането в страничния панел се запазва, видеото продължава да върви. Това е разликата между вложен изглед и копиран компонент.
```

## Връзки

```javascript
import Link from "next/link";

<Link href="/courses">Курсове</Link>
<Link href={`/courses/${course.slug}`}>{course.title}</Link>
```

`next/link` не само сменя адреса без презареждане — Next започва да зарежда страницата предварително, щом връзката се появи на екрана. Затова навигацията се усеща мигновена.

```callout
{"type":"danger","title":"Пак: не `<a href>` вътре в сайта"}
---
Обикновената връзка презарежда цялото приложение. Изключението е външен адрес — там `<a>` е правилният избор.
```

## Специалните файлове

| Файл | Роля |
| --- | --- |
| `page.jsx` | страницата, достъпна на този адрес |
| `layout.jsx` | общ изглед за папката и всичко под нея |
| `loading.jsx` | показва се, докато страницата се зарежда |
| `error.jsx` | показва се при грешка в тази част |
| `not-found.jsx` | страницата 404 |
| `route.js` | адрес за API вместо страница |

Всички са по избор освен `page.jsx` и основния `layout.jsx`.

## Групите на практика

```
app/
├── (marketing)/
│   ├── layout.jsx      светъл изглед с меню за посетители
│   ├── page.jsx        /
│   └── pricing/page.jsx
└── (dashboard)/
    ├── layout.jsx      тъмен изглед със страничен панел
    └── settings/page.jsx
```

Два напълно различни изгледа в един проект, без нито един `if` в кода и без излишна част в адреса.

```takeaways
- Папка = маршрут, `page.jsx` = страница, `layout.jsx` = общ изглед за клона.
- Изгледите се наслагват и не се пречертават при навигация между страници под тях.
- `[скоби]` — динамична част; `(скоби)` — група извън адреса.
- `next/link` навигира без презареждане и зарежда предварително.
